## 개요 (Overview)

웹툰 팝은 **한국 캐릭터-챗 서비스**를 위한, 밝고 활기찬 웹툰·스티커 감성의 시스템이다. 처음 만나는 사람도 부담 없이 "가볍게 말 걸어보게" 만드는 톤이 목표다. 핵심 장치는 **굵은 잉크 테두리 + 딱 떨어지는 하드 오프셋 섀도우**(네오브루탈리즘), **멀티 파스텔 액센트**, **말풍선·스티커 모티프**, **라운드 산세리프(Pretendard)**다.

두 가지 축이 이 시스템을 규정한다:

1. **라이트가 기본이자 유일한 테마.** base(`:root`)는 라이트이고 `color-scheme: light`. 다크는 **폐기**(2026-08-06). 이유: 이 팔레트는 밝은 파스텔 채움 위에 어두운 글자(`--on-bright`)를 얹는 **라이트 전제** 체계다. 다크에서는 주 버튼이 배경보다 6.6배 밝게 떠 화면에서 분리되고, 글자 대비도 2.99:1로 미달했다(라이트에선 같은 조합이 5.3:1). 색을 바꿔 다크를 살리려면 팔레트 전체를 다시 짜야 해서 접었다. ⛔ 다크 재도입 논의는 [[todos]] D1의 결정 기록을 먼저 볼 것.
2. **화면마다 "강도"가 다르다 (2-강도 시스템).** 둘러보는 화면(홈·카탈로그)은 팝을 **세게** 밀어 첫인상을 끌고, 실제로 오래 머무는 **채팅 화면은 차분·미니멀**하게 물러난다. 같은 팔레트, 다른 강도. → [두 강도 시스템](#두-강도-시스템) 참고.

## 색상 & 토큰 (Colors & Tokens)

색은 **oklch가 정본**, hex는 근사값(참고용). 액센트 팔레트(명도 70%대)는 **장식·아트용**이다 — 카드 아트 그라디언트, 배지, 아바타 폴백, 스티커. 글자·링크로 쓸 땐 규칙 3을 따라 명도를 낮춘 `--champ`(55%)를 쓴다.

### 액센트 (아트 팔레트)

| 토큰 | oklch | ~hex | 용도 |
|---|---|---|---|
| `--coral` / `--coral-deep` | `70% .17 22` / `60% .19 22` | `#f4715f` / `#d94a3d` | 로맨스, 브랜드 그라디언트 한 축, hot 배지 |
| `--sky` / `--sky-deep` | `72% .13 232` / `60% .15 245` | `#66ade3` / `#4f80d8` | 미스터리·SF, 내 말풍선 계열 |
| `--lilac` / `--lilac-deep` | `70% .15 300` / `58% .17 300` | `#b57fe4` / `#965ad2` | 판타지, 브랜드 그라디언트, 그림자 틴트 |
| `--mint` / `--mint-deep` | `74% .14 170` / `64% .14 172` | `#5fc9ab` / `#3fb094` | 일상·힐링, NEW 배지 |
| `--sun` / `--sun-deep` | `86% .15 92` / `80% .16 78` | `#e9c247` / `#eea63f` | 형광 하이라이트 바, 스티커, 로그인 CTA |

- 브랜드 그라디언트 = `linear-gradient(135deg, var(--coral), var(--lilac))` (로고 물방울·주 CTA·아바타 폴백).
- **카드 아트 그라디언트는 `.wp-g1`~`.wp-g7` 7종**을 순환시킨다(coral·sun·sky·lilac·mint 조합, 전부 `150deg`). 캐릭터 이미지가 붙기 전까지의 자리표시자.
- 배지 전용 토큰은 없다 — `.wp-badge.hot`=`--coral`, `.wp-badge.new`=`--mint`.

### 표면 · 잉크 · 그림자 (`:root` 발췌)

```css
:root {
  color-scheme: light;                    /* 라이트 단일 테마 */

  /* 표면 — 흰 페이퍼 + 옅은 라일락 틴트 (밝을수록 바닥, 어두울수록 눌림) */
  --ink:           oklch(98.5% 0.012 320); /* ⚠ 이름과 반대: 앱 배경 */
  --surface:       oklch(100% 0 0);        /* 카드·패널 (배경보다 희게 떠오름) */
  --surface-elev:  oklch(97% 0.015 320);   /* hover·모달·상대 말풍선 */
  --surface-high:  oklch(94.5% 0.022 320); /* 활성 */
  --letterbox:     oklch(92% 0.025 320);   /* 최심 표면 */

  /* 주 액센트 = lilac (링크·CTA·활성) — 흰 바탕에서 읽히도록 55%로 내려 잡음 */
  --champ:         oklch(55% 0.17 300);
  --champ-bright:  oklch(47% 0.18 300);    /* hover — 라이트에선 '더 진하게'가 hover */
  --champ-deep:    oklch(41% 0.16 300);    /* pressed */
  --champ-soft:    oklch(95% 0.035 300);   /* 액센트 틴트 표면·포커스 링 */

  /* 보조/강조 = coral (라이브·에러·hot) */
  --crimson:       oklch(55% 0.20 22);
  --crimson-bright:oklch(47% 0.20 22);

  /* 텍스트 (짙은 라일락-잉크) */
  --text:          oklch(27% 0.03 300);    /* 본문 + 컴포넌트 테두리 */
  --text-2:        oklch(46% 0.03 300);    /* 설명·보조 */
  --text-3:        oklch(58% 0.03 300);    /* 메타 */
  --text-faint:    oklch(70% 0.02 300);    /* disabled·placeholder */

  /* 라인 */
  --outline:        oklch(90% 0.02 320);   /* 카드 엣지·구분선(차분 강도용) */
  --outline-strong: oklch(78% 0.03 320);   /* 포커스 입력·강한 구분선 */

  /* 하드 오프셋 섀도우 색 + 밝은 배경 위 글자색 */
  --edge:      var(--text);
  --on-bright: var(--text);

  /* 그림자 */
  --shadow-card: 0 10px 0 -4px oklch(70% .15 300 / .12), 0 18px 40px -22px oklch(40% .08 300 / .5);
  --shadow-pop:  0 20px 0 -8px oklch(70% .15 300 / .14), 0 26px 55px -24px oklch(40% .08 300 / .6);
  --shadow-soft: 0 18px 40px -30px oklch(40% .08 300 / .55);  /* [약] 채팅용 확산 그림자 */
}
```

**규칙 1 — 하드 섀도우는 `var(--edge)`로.** 라이트에선 `--edge`가 곧 잉크(`--text`)지만, 직접 `var(--text)`를 쓰지 말고 `--edge`를 거친다. 섀도우 색을 한 곳에서 조절할 수 있게 남겨 두는 장치다.

**규칙 2 — 밝은 액센트 위 글자는 `var(--on-bright)`.** sun 버튼·형광 하이라이트 바·스티커·배지처럼 명도 높은 면 위의 글자에 쓴다.

**규칙 3 — 액센트를 글자·링크로 쓸 땐 명도를 낮춘다.** 아트 팔레트(70%대)를 흰 바탕에서 **글자·링크·아이콘**으로 쓰면 대비가 모자란다(`lilac 70%` = 2.84:1). 그래서 주 액센트 `--champ`는 **55%**(5.23:1)다.

### 레거시 별칭

`:root` 하단에 옛 컴포넌트가 물고 있는 별칭이 매핑돼 있다. **지우지 말 것.**

| 별칭 | 실제 | 비고 |
|---|---|---|
| `--bg` | `var(--ink)` | body 배경 |
| `--panel` | `var(--surface)` | |
| `--primary` / `--primary-dark` | `var(--champ)` / `var(--champ-bright)` | |
| `--muted` | `var(--text-2)` | |
| `--border` | `var(--outline)` | |
| `--bot` | `var(--surface-elev)` | 상대 말풍선 |
| `--me` | `oklch(93% .04 245)` | 내 말풍선(sky 틴트) |
| `--me-edge` | `oklch(80% .07 245)` | 내 말풍선 테두리(틴트보다 한 단 진하게) |

### 레거시 이름 주의

Reel Theory 시스템의 토큰 **이름을 유지한 채 값만 갈아끼우는** 방식으로 이식했다. 덕분에 컴포넌트를 한 줄도 안 고치고 전체가 리스킨됐고, 라이트 전환도 `:root` 한 블록으로 끝났다. 대신 이름이 뜻과 어긋난다:

- `--ink` = **배경**(페이퍼), `--text` = **글자·테두리**(잉크)
- `--champ`("샴페인") = 실제로는 **라일락**

이름을 바꾸려면 2,000줄 전역 치환 + 회귀 확인이 필요해 하지 않는다. **이름의 원뜻이 아니라 `styles.css`의 주석에 적힌 역할을 따를 것.**

### 앰비언트 배경

body에 은은한 컬러 글로우. **알파는 낮게** — 여백 많은 화면에서 배경이 얼룩처럼 뜬다(초안의 `.24/.22/.16`은 과했다):
```css
background:
  radial-gradient(60% 40% at 12% -6%,  oklch(80% .12 168 / .13), transparent 60%),
  radial-gradient(50% 40% at 96% 2%,   oklch(75% .14 300 / .12), transparent 60%),
  radial-gradient(46% 36% at 78% 40%,  oklch(78% .13 232 / .08), transparent 60%),
  var(--bg);
background-attachment: fixed;
```

## 두 강도 시스템 (Two-Intensity System)

같은 토큰·같은 팔레트를, 화면 성격에 따라 **강(强) / 약(弱)** 두 강도로 적용한다. 이게 웹툰 팝의 핵심 규칙이다.

| | **강 (Pop) — 둘러보기 홈·카탈로그·폼·메이커 CTA** | **약 (Calm) — 채팅 화면** |
|---|---|---|
| 테두리 | `2px solid var(--text)` | `1px solid var(--outline)` |
| 그림자 | 하드 오프셋(`0 Npx 0 var(--edge)`) + `--shadow-card`/`--shadow-pop` | `--shadow-soft`(확산)만, **하드 오프셋 없음** |
| 채움 | 쨍한 액센트·그라디언트 | 표면색 위주, 액센트는 **포인트에만**(헤더 아바타·전송 버튼·내 말풍선 틴트) |
| 모서리 | `--r-card`(20px) / 알약은 `--r-pill` | 말풍선 18px + 꼬리쪽 6px 각짐 |
| 목적 | 첫인상·유입·개성 최대 | 대화 몰입·눈 피로 최소 (긴 세션) |

> 이유: 채팅은 오래 머무는 공간이라 굵은 테두리·하드 섀도우·쨍한 색을 그대로 쓰면 시끄럽고 눈이 피로하다. 팝 정체성은 **아바타·전송 버튼 같은 포인트**로만 남긴다. (A/B/C 비교 후 A안 채택.)

강도는 **별도 토큰 세트가 아니라 컴포넌트 셀렉터로** 구현돼 있다 — 카탈로그·폼 컴포넌트가 `2px var(--text)` + `0 Npx 0 var(--edge)`를 직접 들고, 채팅 스코프(`.chat*`)는 `1px var(--outline)` + `--shadow-soft`를 쓴다. 강도용 중간 토큰(`--border-strong` 같은)을 새로 만들 필요는 없었다.

## 타이포그래피 (Typography)

- **단일 서체**: `--font-sans: 'Pretendard', 'Apple SD Gothic Neo', 'Malgun Gothic', system-ui, …`
  `--font-display` · `--font-serif` · `--font-kr-serif`는 전부 `var(--font-sans)`로 매핑돼 있다(레거시 별칭 — **명조는 쓰지 않는다**, Reel Theory 잔재).
  `--font-mono: 'JetBrains Mono', …`는 메타 수치·모노그램용.
- 성격: 굵고(900) 큼직하게, 자간 좁게(`-0.01 ~ -0.04em`). 제목은 무겁게, 본문은 400~500.

실제 타입 스케일(`styles.css` 기준):

| 역할 | 값 |
|---|---|
| 히어로 제목 (`.hero-title`) | `clamp(2.1rem, 5.4vw, 3.4rem)` / 900 / `-0.035em` / line-height 1.18 |
| 페이지 제목 (`.page-head h1,h2`) | `clamp(1.6rem, 3.4vw, 2.2rem)` / 900 / `-0.03em` |
| 아바타 모노그램 (`.wp-mono`) | `clamp(2.6rem, 6vw, 4rem)` / 900 / `-0.04em` |
| 히어로 보조문 | `16px` / 1.7 / `--text-2` / `max-width: 46ch` |
| 아이브로 필 | `12.5px` / 800 |
| 칩 | `13px` / 800 |
| 폼 라벨 | `13.5px` / 800 |
| 배지 | `0.72rem` / 900 |

시그니처: 히어로 제목 일부를 `.hl`로 감싸고 뒤에 **형광 하이라이트 바**(`linear-gradient(100deg, var(--sun), var(--coral))`, `rotate(-1.4deg)`)를 깐다. 이때 글자는 `--on-bright`.

## 간격 · 라운드 · 그림자 (Spacing / Radius / Elevation)

- **간격 토큰은 없다.** 컴포넌트가 4px 배수 px를 직접 쓴다(주로 8·12·16·24·32). 스케일 토큰(`--s-1`…)을 새로 도입하려면 전면 치환이라 하지 않았다 — **주변 코드의 배수를 따를 것.**
- 라운드: `--r-btn: 12px`(버튼·입력) · `--r-card: 20px` · `--r-modal: 22px` · `--r-pill: 9999px`. 말풍선·스티커의 18px처럼 일부는 하드코딩이다.
- 컨테이너: `.content { max-width: 1040px; margin: 0 auto; padding: 32px 24px; }`
- 상단바 높이는 `--topbar-h: 60px` 하나로 묶여 있다 — **사이드바·채팅 높이 계산이 전부 이 값을 따라가니 바꿀 때 주의.**
- 엘리베이션 = **표면 밝기 차 + 하드 오프셋(강 강도)**. 카드는 `--surface`(순백, 배경보다 밝음) + `--shadow-card`, hover 시 살짝 떠오르며 `--shadow-pop`.

## 컴포넌트 (Components)

강도 표기: **[강]** = 홈/카탈로그/폼, **[약]** = 채팅.

- **Nav** **[강]**: 상단 바(`--topbar-h`), `--surface` 배경 + `2px solid var(--text)` 하단 엣지. 로고 = **그라디언트 물방울 점 + 잉크 워드마크**(`--text`, 900). ⚠ 워드마크에 액센트색을 쓰지 않는다 — 색은 물방울이 담당하고, 둘 다 색이면 액센트가 두 번 들어간다. + 링크 + `로그인` CTA(sun 배경·`--on-bright` 글자·`0 4px 0 var(--edge)`).
- **Hero** **[강]**: 아이브로 필(`--champ-soft` 바닥) → 900 대형 제목(`.hl` 형광 바) → 보조문(`--text-2`) → 버튼 2개(주=그라디언트, 보조=`.btn-ghost`). 오른쪽에 떠다니는 **스티커 말풍선**(꼬리 달린, `rotate(-3deg)`, `float` 6s). 스티커 글자는 `--on-bright`.
  - **비로그인 방문자에게만 노출한다.** 로그인 사용자에겐 매번 큰 배너가 소음이라 컴팩트한 페이지 헤더만 남긴다.
  - `.hl` 형광 바는 `isolation: isolate` + `::before { z-index: -1 }`. isolation이 없으면 body 배경 뒤로 빠져 안 보인다.
  - **히어로가 h1을 가져가므로** 같은 화면의 `.page-head` 제목은 비로그인일 때 h2로 내린다(h1은 페이지당 하나). CSS는 `.page-head h1, .page-head h2`를 함께 잡는다.
  - **스티커는 `max-width: 780px`에서 숨긴다**(좁은 화면에서 본문을 덮는다). `styles.css`의 다른 `860px` 미디어쿼리는 `.chat-aside` 폭 전용이니 히어로 규칙을 거기 얹지 말 것.
- **장르 칩 / 필터 칩** **[강]** (`.chip`): 알약, `2px var(--text)` + `0 3px 0 var(--edge)`, 13px/800. hover 시 `-2px` 떠오르며 섀도우 5px, press 시 눌림. 활성(`.chip.active`)은 **잉크 채움 + `--ink` 글자 + `0 3px 0 var(--champ)`**. 카탈로그 필터는 줄바꿈 대신 한 줄 가로 스크롤(드래그 스크롤은 JS 담당).
- **캐릭터 카드** **[강]**: 세로 카드. 상단 정사각(`aspect-ratio: 1/1`) 아트 영역(현재는 `.wp-g1`~`.wp-g7` 그라디언트 + 모노그램 → [캐릭터 아트](#캐릭터-아트--이미지)), 좌상단 `.wp-badge`(NEW=mint / HOT=coral), 하단 본문 = 이름(900) + 한 줄 대사(`--text-2`) + 장르 칩 + **💬 대화 시작** 버튼. `2px var(--text)` + `--shadow-card`, hover 시 떠오름. 그리드는 `repeat(auto-fill, minmax(240px, 1fr))` / gap 24px.
- **채팅 화면** **[약]**: 헤더(아바타 · 이름 · 메타 한 줄 · 설정) → 스레드 → 입력 바. 대화 전체를 **1px 테두리 + 부드러운 그림자의 카드 패널** 하나로 감싼다(`.chat-main`).
  - 헤더/입력 구분선 `1px var(--outline)`.
  - 헤더 = 아바타(44px) + 이름(800/19px) + 메타 행(`@제작자` · 모델 배지 · ●대화중). 캐릭터 소개는 헤더가 아니라 **빈 대화 인트로**에 크게 둔다.
  - 말풍선: 상대 = `--bot`(=`--surface-elev`) + `1px var(--outline)`, 왼아래 6px 각짐. 나 = `--me` + `--me-edge` 테두리, 오른아래 6px. **하드 섀도우·굵은 테두리 없음.**
  - 포인트 컬러만 팝: 헤더 아바타(그라디언트), 전송 버튼(그라디언트 원형). 설정 톱니는 고스트로 낮춘다.
  - 설정 패널은 **뷰포트 고정이 아니라 대화 패널 옆 열(column)** — `.chat` 안의 형제다. `position: fixed`로 두면 카드 패널 위를 덮는다.
  - 스크롤바: 보이는 막대 6px + 투명 테두리로 **클릭 영역 14px**. `scrollbar-width: thin`은 쓰지 않는다(잡기 어렵다).
- **메이커 CTA** **[강]**: 큰 라운드 블록, 앰비언트 그라디언트 배경 + `2px var(--text)` + `--shadow-pop`. 카피 + 흔들리는(wobble) 블롭 아바타.
- **버튼**:
  - Primary = 브랜드 그라디언트 채움 + **`--on-bright`(잉크) 글자**, `2px var(--text)` + `0 6px 0 var(--edge)`, hover `translateY(-3px)`·press `translateY(2px)`(섀도우 동반 축소).
  - Ghost(`.btn-ghost`) = `--surface` 배경 + `2px var(--text)` + `0 4px 0 var(--edge)`, `--r-pill`, 900.
  - 전송(원형) = 그라디언트, [약] 채팅에선 하드 섀도우 대신 부드러운 그림자.
  - Danger(`.confirm-actions button.danger`) = 채움 위 **흰 글자**(잉크 글자로 두면 라이트에서 안 읽힌다).
  - ⚠ **pop(잉크 테두리 + 하드 섀도우)을 전역 `button`에 걸지 않는다.** 걸면 드롭다운 메뉴 항목·채팅 전송 버튼처럼 pop이면 안 되는 곳까지 샌다.
  - ⚠ **`.form-card button`도 너무 넓다** — 장르 칩이 폼 카드 안에 있어 `.chip.active`의 `--champ` 섀도우를 덮어쓴다. 실제 셀렉터는 CTA 자리로만: **`.auth-card form > button, .form-actions button:not(.link-btn)`** (취소는 `.link-btn`이라 자동 제외).
- **활성 상태 = 잉크 반전**: 선택된 칩, 사이드바의 현재 방 등 "지금 여기"는 **`--text`로 채우고 글자를 `--ink`로 반전**한다(`.room-item.active` ≡ `.chip.active`). 화면 전체가 한 문법으로 읽히게 하는 규칙. ⚠ 잉크로 채운 행 위의 `⋮`는 **`.room-item.active ~ .room-menu-btn`**으로 반전색을 되돌려야 보인다.
- **배지**(`.wp-badge`): 알약, `2px var(--text)` + `0 2px 0 var(--edge)`, 글자 `--on-bright`. `new`=`--mint`, `hot`=`--coral`.
- **스티커 말풍선**: `--sun` 바닥 + `2px var(--text)` + `--shadow-card`, 꼬리는 회전한 정사각형의 오른/아래 테두리로 만든다. 글자 `--on-bright`.
- **입력**: `--r-btn` 라운드. [강]은 `2px var(--text)` + 포커스 링 `0 0 0 3px var(--champ-soft)`, [약]은 `1px var(--outline)`.
- **폼**: 카드는 `2px` 잉크 + 하드섀도우. 라벨은 굵은 한글(`13.5px`/800·`--text`), 필수 표시는 `*`(액센트색). ⚠ **대문자·넓은 자간을 쓰지 않는다** — `text-transform: uppercase`는 한글에 아무 효과가 없고, 작은 대문자 라벨은 Reel Theory 잔재다.
- **툴팁/토글**: `.tog-tip` 배경은 라이트 기준으로 잡혀 있다(다크 시절 값에서 고친 곳).

## 캐릭터 아트 · 이미지

- **전략 = 제작자 업로드** (확정). 각 캐릭터는 **제작자가 올린 일러스트**를 정사각(1:1)으로 담는다. 카드·채팅 헤더·아바타에서 공통 사용.
- **아직 구현 전이다.** `ChatCharacter`에 `imageUrl` 필드가 없고, 현재 아바타는 이름 첫 글자 모노그램 + 그라디언트다. 초기엔 URL 입력 → 이후 업로드/스토리지. 규격·검열 처리 필요. → [[todos]] A1.
- **폴백**(이미지 없을 때): 브랜드 그라디언트 배경 + 이름 첫 글자 모노그램(`.wp-mono`). 목업의 SVG 초상은 "이미지가 들어가면 이렇게 보인다"는 자리표시일 뿐, 실제 스타일은 업로더 몫.
- 업로드 이미지는 자기 색을 그대로 유지한다. 카드 배경·테두리만 시스템이 책임진다.
- 비율: 카드·아바타 **1:1 정사각**. 스트리밍 타일 비율·세로 포스터 강요하지 않는다.

## 모션 (Motion)

- **이징 토큰은 `--ease-out: cubic-bezier(.22, 1, .36, 1)` 하나뿐이다.** 지속시간 토큰(`--dur`)은 없고 컴포넌트가 `0.16s`~`0.24s`를 직접 쓴다(hover·press는 0.16~0.2, 레이아웃 변화는 0.24~0.3). 새 값은 이 범위를 따를 것.
- 상호작용: 카드 hover 떠오름, 버튼 hover 시 위로 뜨며 하드 섀도우 커지고 press 시 눌림(섀도우 축소) — "누르는 맛".
- 데코: 스티커 `float`(상하 6s), 메이커 블롭 `wobble`, 사이드바 진입 `aside-in`(0.28s), 상태 점 `ns-blink`(1.6s).
- **`prefers-reduced-motion: reduce`** 시 `* { animation: none; transition: none; }`로 전부 끈다(파일 맨 끝). 필수.

## 아이콘 & 이모지 (Iconography & Emoji)

- **이모지는 유지** (확정). 카피의 💗 ✦ ㅋㅋㅋㅋ 💬 등은 웹툰 팝의 가벼운 톤을 만드는 장치 → 커스텀 아이콘으로 대체하지 않는다.
- 단, **의미 전달을 이모지에만 의존하지 않는다**(접근성): 이모지는 장식, 옆에 텍스트 라벨을 함께 둔다. 순장식 이모지는 `aria-hidden`.
- 아이콘이 필요할 땐 굵은(2px 내외) 둥근 스트로크의 심플 세트. 날카로운 기하보다 둥글게.

## 보이스 & 톤 (Voice & Tone)

- **친구가 말 거는 톤.** 반말/구어체, 가볍고 다정하게. "가볍게 말 걸어보는" 진입장벽 최소.
- 캐릭터 대사는 한 줄 훅(로그라인)으로: "오늘 밤도 네 얘기, 내가 다 들어줄게." 장르 태그 나열 대신 목소리를 보여준다.
- 이모지·`ㅋㅋ` 같은 캐주얼 마크 허용(과하지 않게).
- 빈 상태: 무겁지 않게. "아직 준비 중이야 — 곧 새 친구가 올라와요." 식.
- 정직한 카피: **가짜 지표·후기·숫자 금지**(예: "지금 1,000명 접속 중" 같은 조작 금지). 없는 수치는 쓰지 않는다.

## Do / Don't

**Do**
- 라이트를 base로. 하드 섀도우는 `--edge`, 밝은 배경 글자는 `--on-bright`.
- 액센트를 **글자·링크**로 쓸 땐 명도를 55% 안팎까지 낮춘다(70%대는 흰 바탕에서 안 읽힌다).
- 화면 성격에 따라 강/약 강도를 지킨다: 카탈로그는 팝, **채팅은 차분**.
- 액센트는 멀티로 즐겁게 쓰되 잉크 테두리로 묶어 정돈.
- 캐릭터 대사·이미지가 주인공. 카드는 그걸 담는 틀.

**Don't**
- 채팅 화면에 홈처럼 굵은 테두리·하드 섀도우·쨍한 색을 그대로 밀지 않는다(눈 피로).
- 명조(serif)·필름그레인·레터박스 등 Reel Theory 잔재를 섞지 않는다.
- 하드 오프셋 섀도우에 `var(--text)`를 직접 쓰지 않는다 → `var(--edge)`(섀도우 색을 한 곳에서 조절하기 위해).
- **다크 테마를 다시 얹지 않는다.** 이 팔레트는 라이트 전제라 표면만 뒤집으면 주 버튼이 깨진다 — 하려면 팔레트를 새로 짜야 한다.
- 밝은 sun/하이라이트/스티커 위에 밝은 글자를 얹지 않는다 → `var(--on-bright)`.
- 코드에 없는 토큰 이름(`--paper`, `--line`, `--s-*`, `--r-lg`)을 새로 쓰지 않는다.
- 가짜 지표·과장 마케팅 카피·느낌표 남발 금지.
- 의미를 이모지 단독에 싣지 않는다(텍스트 라벨 병기).

## 코드 규약 (Implementation Notes)

이 시스템을 `src/styles.css`에서 다룰 때 지켜야 하는 것들. (무엇이 언제 이식됐는지 같은 **작업 진척은 여기 적지 않는다** — 메모리 `todos.md`가 관리한다.)

- **색을 직접 쓰지 않는다.** 하드코딩된 색이 0건이라, 토큰 값만 갈아끼우면 전체가 리스킨된다. 라이트 전환도 `:root` 한 블록으로 끝났다. 이 성질을 깨지 말 것.
- **토큰 이름이 뜻과 어긋난다**(`--ink`가 배경, `--champ`가 라일락) → [레거시 이름](#레거시-이름-주의). 이름을 고치지 말고 주석의 역할을 따른다.
- **레거시 별칭(`--bg/--panel/--primary/--muted/--border/--me/--bot`)을 지우지 말 것.** `:root` 하단에 매핑돼 있고 컴포넌트들이 물려 있다.
- **스타일만 확인할 땐 앱에 임시 라우트를 만들지 않는다.** 실제 `styles.css`를 `<link>`로 불러오는 정적 HTML에 같은 클래스로 마크업을 얹으면 된다 — 같은 파일이라 검증이 유효하고 앱에 잔재가 안 남는다. (채팅은 로그인 가드 안이라 이 방법이 특히 유용하다.) ⚠ 과거에 임시 프리뷰 라우트가 untracked 파일을 import해 `main`을 빌드 불가로 만든 적이 있다 — 새 파일을 만든 커밋은 `git status`로 untracked를 확인할 것.
- 헤드리스 스크린샷 검증: `firefox --headless --no-remote --profile <임시프로필> --window-size=1280,900 --screenshot <절대경로> <url>`. **전용 프로필 없이는 실패한다.** 메인(`/`)은 `HomeLayout`이 로딩 중 `null`을 그려 **빈 화면으로 찍히는 게 정상**이다(버그 아님).
- 참고 목업(자체완결 HTML): 라이트(기본) `7102f03f`, 채팅 강도비교 `88d8429f` — claude.ai/code/artifact/ 하위. 다크 목업 `0cc8fa61`은 폐기. **목업은 참고용이고 값의 정본은 `styles.css`다.**
