# 웹툰 팝 (Webtoon Pop)

> 속삭(soksak) 프론트엔드 디자인 시스템 · **단일 소스**
> 확정 2026-07-29. 이전 *Reel Theory*(영화 카탈로그 무드) 시스템은 폐기 — 이 파일이 대체한다. 옛 명세는 git 히스토리 참고.
>
> ⚠️ **토큰 이름이 코드와 다르다.** 이 문서는 `--paper`(배경)/`--ink`(글자·테두리)로 부르지만, `styles.css`는 레거시 이름을 유지해 **`--ink`가 배경**이고 **`--text`가 글자·테두리**다. 정반대다. 코드를 만질 땐 아래 [토큰 이름 대응표](#토큰-이름-대응표)를 먼저 볼 것.

## 개요 (Overview)

웹툰 팝은 **한국 캐릭터-챗 서비스**를 위한, 밝고 활기찬 웹툰·스티커 감성의 시스템이다. 처음 만나는 사람도 부담 없이 "가볍게 말 걸어보게" 만드는 톤이 목표다. 핵심 장치는 **굵은 잉크 테두리 + 딱 떨어지는 하드 오프셋 섀도우**(네오브루탈리즘), **멀티 파스텔 액센트**, **말풍선·스티커 모티프**, **라운드 시스템 산세리프**다.

두 가지 축이 이 시스템을 규정한다:

1. **라이트가 기본이자 유일한 테마.** base(`:root`)는 라이트. 다크는 **폐기**(2026-08-06). 이유: 이 팔레트는 밝은 파스텔 채움 위에 어두운 글자(`--on-bright`)를 얹는 **라이트 전제** 체계다. 다크에서는 주 버튼이 배경보다 6.6배 밝게 떠 화면에서 분리되고, 글자 대비도 2.99:1로 미달했다(라이트에선 같은 조합이 5.3:1). 색을 바꿔 다크를 살리려면 팔레트 전체를 다시 짜야 해서 접었다. ⛔ 다크 재도입 논의는 [[todos]] A0-3의 결정 기록을 먼저 볼 것.
2. **화면마다 "강도"가 다르다 (2-강도 시스템).** 둘러보는 화면(홈·카탈로그)은 팝을 **세게** 밀어 첫인상을 끌고, 실제로 오래 머무는 **채팅 화면은 차분·미니멀**하게 물러난다. 같은 팔레트, 다른 강도. → [두 강도 시스템](#두-강도-시스템) 참고.

## 색상 & 토큰 (Colors & Tokens)

액센트 팔레트(명도 70%대)는 **장식·아트용**이다 — 카드 아트 그라디언트, 배지, 아바타 폴백, 버튼 채움. 글자·링크로 쓸 땐 규칙 3을 따라 명도를 낮춘다. 색은 **oklch가 정본**, hex는 근사값(참고용).

### 액센트 (테마 공통)

| 토큰 | oklch | ~hex | 용도 |
|---|---|---|---|
| `--coral` / `--coral-deep` | `70% .17 22` / `60% .19 22` | `#f4715f` / `#d94a3d` | 로맨스, 주 CTA 그라디언트 한 축, hot 배지 |
| `--sky` / `--sky-deep` | `72% .13 232` / `60% .15 245` | `#66ade3` / `#4f80d8` | 미스터리·SF, 내 말풍선 |
| `--lilac` / `--lilac-deep` | `70% .15 300` / `58% .17 300` | `#b57fe4` / `#965ad2` | 판타지, 브랜드 그라디언트, 그림자 틴트 |
| `--mint` / `--mint-deep` | `80% .13 168` / `66% .14 170` | `#6fd3b3` / `#35b7a0` | 일상·힐링, "대화 중" 상태 |
| `--sun` / `--sun-deep` | `88% .15 92` / `80% .16 78` | `#f0c948` / `#eea63f` | 강조 스트라이프, 로그인·하이라이트 바 |
| `--badge-new` | `72% .16 145` | 그린 | NEW 배지 |
| `--badge-hot` | `70% .18 22` | 코랄 | 인기 배지 |

브랜드 그라디언트 = `linear-gradient(135deg, var(--coral), var(--lilac))` (로고 점·주 버튼·아바타 폴백).

### 표면 · 잉크 · 그림자 (테마별)

```css
/* ===== BASE = LIGHT (:root) — 유일한 테마 ===== */
:root{
  --paper:       oklch(98.5% 0.012 320); /* 앱 배경 (옅은 라일락 틴트 페이퍼) */
  --paper-2:     oklch(100% 0 0);        /* 카드·패널 (배경보다 희게 떠오름) */
  --paper-tint:  oklch(96% 0.02 320);    /* 입력·hover·chip 바닥 */
  --ink:         oklch(27% 0.03 300);    /* 본문 + 테두리 */
  --ink-soft:    oklch(46% 0.03 300);    /* 보조 텍스트 */
  --line:        oklch(90% 0.02 320);    /* 얇은 구분선(차분 강도용) */

  /* 하드 오프셋 섀도우 색: 라이트는 잉크(거의 검정) */
  --edge:        var(--ink);
  --shadow-card: 0 10px 0 -4px oklch(70% .15 300 / .12), 0 18px 40px -22px oklch(40% .08 300 / .5);
  --shadow-pop:  0 20px 0 -8px oklch(70% .15 300 / .14), 0 26px 55px -24px oklch(40% .08 300 / .6);

  /* 밝은 배경(sun/하이라이트/스티커) 위에 올라가는 글자색 */
  --on-bright:   var(--ink);
}
```

**규칙 1 — 하드 섀도우는 `var(--edge)`로.** 라이트에선 `--edge`가 곧 잉크지만, 직접 `var(--ink)`를 쓰지 말고 `--edge`를 거친다. 섀도우 색을 한 곳에서 조절할 수 있게 남겨 두는 장치다.

**규칙 2 — 밝은 액센트 위 글자는 `var(--on-bright)`.** sun 버튼·형광 하이라이트 바·스티커처럼 명도 높은 면 위의 글자에 쓴다.

**규칙 3 — 액센트를 채움에 쓸 땐 명도를 낮춘다.** 액센트 팔레트(70%대)는 *장식·아트*용이다. 흰 바탕에서 **글자·링크·아이콘**으로 쓰면 대비가 모자란다(`lilac 70%`는 흰 배경 대비 2.84:1). 그래서 `styles.css`의 주 액센트 `--champ`는 **55%**로 내려 잡았다(5.23:1).

### 토큰 이름 대응표

이 문서와 `styles.css`의 이름이 다르다. **코드를 고칠 땐 오른쪽 열을 따른다.**

| 이 문서 | `styles.css` | 값 |
|---|---|---|
| `--paper` | **`--ink`** ⚠ | `oklch(98.5% .012 320)` 앱 배경 |
| `--paper-2` | `--surface` | `oklch(100% 0 0)` 카드 |
| `--paper-tint` | `--surface-elev` / `--surface-high` | `97%` / `94.5%` |
| `--ink` | **`--text`** ⚠ | `oklch(27% .03 300)` 글자·테두리 |
| `--ink-soft` | `--text-2` | `oklch(46% .03 300)` |
| `--line` | `--outline` | `oklch(90% .02 320)` |
| (주 액센트) | `--champ` | `oklch(55% .17 300)` — 링크·CTA |
| `--edge` · `--on-bright` | 동일 | `var(--text)` |

### 앰비언트 배경

body에 은은한 컬러 글로우. **알파는 낮게** — 여백 많은 화면에서 배경이 얼룩처럼 뜬다(초안의 `.24/.22/.16`은 과했다):
```css
background:
  radial-gradient(60% 40% at 12% -6%,  oklch(80% .12 168 / .13), transparent 60%),
  radial-gradient(50% 40% at 96% 2%,   oklch(75% .14 300 / .12), transparent 60%),
  radial-gradient(46% 36% at 78% 40%,  oklch(78% .13 232 / .08), transparent 60%),
  var(--paper);
```

## 두 강도 시스템 (Two-Intensity System)

같은 토큰·같은 팔레트를, 화면 성격에 따라 **강(强) / 약(弱)** 두 강도로 적용한다. 이게 웹툰 팝의 핵심 규칙이다.

| | **강 (Pop) — 둘러보기 홈·카탈로그·메이커 CTA** | **약 (Calm) — 채팅 화면** |
|---|---|---|
| 테두리 | `2px solid var(--ink)` | `1px solid var(--line)` |
| 그림자 | 하드 오프셋(`0 Npx 0 var(--edge)`) + `--shadow-card/pop` | 부드러운 확산 그림자만, **하드 오프셋 없음** |
| 채움 | 쨍한 액센트·그라디언트 | 표면색 위주, 액센트는 **포인트에만**(헤더 아바타·전송 버튼·내 말풍선 틴트) |
| 모서리 | `--r-lg`(28px) 크게 | `--r-md`(18px) + 꼬리쪽 6px |
| 목적 | 첫인상·유입·개성 최대 | 대화 몰입·눈 피로 최소 (긴 세션) |

> 이유: 채팅은 오래 머무는 공간이라 굵은 테두리·하드 섀도우·쨍한 색을 그대로 쓰면 시끄럽고 눈이 피로하다. 팝 정체성은 **아바타·전송 버튼 같은 포인트**로만 남긴다. (A/B/C 비교 후 A안 채택.)

구현 힌트: 강도는 컴포넌트 기본값으로 두되, 채팅 영역은 래퍼(예: `.chat` 스코프)에서 테두리·그림자 토큰을 얇은 값으로 재정의하거나, `.pop`(강) 유틸리티를 카탈로그 컴포넌트에만 부여한다.

## 타이포그래피 (Typography)

- **UI/디스플레이 공통**: 라운드 시스템 산세리프.
  `--font-ui: "Apple SD Gothic Neo","Malgun Gothic",system-ui,-apple-system,"Segoe UI",sans-serif;`
  실제 이식 시 라운드 웹폰트(예: Pretendard, 또는 둥근 고딕 계열) 도입 검토. **명조(serif)는 쓰지 않는다**(Reel Theory 잔재).
- 성격: 굵고(=900) 큼직하게, 자간 살짝 좁게(`-0.02 ~ -0.035em`). 제목은 무겁게, 본문은 500.

타입 스케일(clamp, 반응형):
| 역할 | 크기 |
|---|---|
| Hero | `clamp(2.6rem, 7vw, 5rem)` / 900 / `-0.035em` |
| 2XL (섹션 제목) | `clamp(1.5rem, 3.4vw, 2.4rem)` / 900 |
| LG (카드 이름) | `1.25rem` / 900 |
| MD (본문·버튼) | `1rem` |
| SM (칩·보조) | `0.875rem` / 700~800 |
| XS (배지·아이브로) | `0.78rem` / 800 |

시그니처: 히어로 제목 일부를 `.hl`로 감싸고 뒤에 **형광 하이라이트 바**(sun→coral 그라디언트, 살짝 회전)를 깐다. 이때 글자는 `--on-bright`.

## 컴포넌트 (Components)

강도 표기: **[강]** = 홈/카탈로그, **[약]** = 채팅.

- **Nav** **[강]**: 상단 바, 굵은 `2px var(--ink)` 하단 엣지. 로고 = **그라디언트 물방울 점 + 잉크 워드마크**(`--ink`, 900). ⚠ 워드마크에 액센트색을 쓰지 않는다 — 색은 물방울이 담당하고, 둘 다 색이면 액센트가 두 번 들어간다. + 링크 + `로그인` CTA(sun 배경·`--on-bright` 글자·`0 4px 0 var(--edge)`).
- **Hero** **[강]**: 아이브로 필 → 900 대형 제목(`.hl` 형광 바) → 보조문(`--ink-soft`) → 버튼 2개(주=그라디언트, 보조=`.btn-ghost`). 오른쪽에 떠다니는 **스티커 말풍선**(꼬리 달린, 살짝 회전, `float`). 스티커 글자는 `--on-bright`.
  - **비로그인 방문자에게만 노출한다.** 로그인 사용자에겐 매번 큰 배너가 소음이라 컴팩트한 페이지 헤더만 남긴다.
  - `.hl` 형광 바는 `isolation: isolate` + `::before { z-index: -1 }`. isolation이 없으면 body 배경 뒤로 빠져 안 보인다.
- **카테고리 필** **[강]**: 알약 버튼 가로 나열, `2px var(--ink)` + `0 3px 0 var(--edge)`. 활성(`is-on`)은 잉크 채움 + 반전 글자.
- **캐릭터 카드** **[강]**: 세로 카드. 상단 정사각(`aspect-ratio:1/1`) **초상 이미지**(→ [캐릭터 아트](#캐릭터-아트--이미지)), 좌상단 배지(NEW/인기), 하단 본문 = 이름(900) + 한 줄 대사(`--ink-soft`) + 장르 칩 + **💬 대화 시작** 버튼. `2px var(--ink)` + `--shadow-card`, hover 시 살짝 떠오름.
- **채팅 화면** **[약]** — *이식 완료 (2026-08-06)*: 헤더(아바타 · 이름 · 메타 한 줄 · 설정) → 스레드 → 입력 바. 대화 전체를 **1px 테두리 + 부드러운 그림자의 카드 패널** 하나로 감싼다(`.chat-main`).
  - 헤더/입력 구분선 `1px var(--line)`.
  - 헤더 = 아바타(44px) + 이름(800/19px) + 메타 행(`@제작자` · 모델 배지 · ●대화중). 캐릭터 소개는 헤더가 아니라 **빈 대화 인트로**에 크게 둔다.
  - 말풍선: 상대 = `--paper-tint` + `1px var(--line)`, 왼아래 6px 각짐. 나 = `--sky` 밝은 틴트 `oklch(93% .04 245)` + 한 단 진한 테두리, 오른아래 6px. **하드 섀도우·굵은 테두리 없음.**
  - 포인트 컬러만 팝: 헤더 아바타(그라디언트), 전송 버튼(그라디언트 원형). 설정 톱니는 고스트로 낮춘다.
  - 설정 패널은 **뷰포트 고정이 아니라 대화 패널 옆 열(column)**. 고정하면 카드 패널 위를 덮는다.
  - 스크롤바: 보이는 막대 6px + 투명 테두리로 **클릭 영역 14px**. `scrollbar-width: thin`은 쓰지 않는다(잡기 어렵다).
- **메이커 CTA** **[강]**: 큰 라운드 블록(`--r-xl`), 앰비언트 그라디언트 배경 + `2px var(--ink)` + `--shadow-pop`. 카피 + 흔들리는(wobble) 블롭 아바타. 카피는 "이미지를 올리면 카드가 완성" — 업로드 서사를 강조.
- **버튼**:
  - Primary = 브랜드 그라디언트 채움 + **`--on-bright`(잉크) 글자**, `2px var(--ink)` + `0 6px 0 var(--edge)`, hover `translateY(-3px)`·press `translateY(2px)`(섀도우 동반 축소).
  - Ghost = `--paper-2` 배경 + `2px var(--ink)` + `0 4px 0 var(--edge)`.
  - 전송(원형) = 그라디언트, [약] 채팅에선 하드 섀도우 대신 부드러운 그림자.
  - ⚠ **pop(잉크 테두리 + 하드 섀도우)을 전역 `button`에 걸지 않는다.** 걸면 드롭다운 메뉴 항목·채팅 전송 버튼처럼 pop이면 안 되는 곳까지 테두리가 샌다. **주 CTA를 감싸는 컨테이너로 좁혀서** 준다(폼이면 카드/액션 영역 안의 `button:not(.link-btn)` — 취소는 텍스트 버튼이라 자동 제외).
- **활성 상태 = 잉크 반전**: 선택된 칩, 사이드바의 현재 방 등 "지금 여기"를 나타내는 것은 **잉크로 채우고 글자를 반전**한다. 화면 전체가 한 문법으로 읽히게 하는 규칙. 단 잉크로 채운 면 위에 얹힌 아이콘(`⋮` 등)은 반전색으로 되돌려야 보인다.
- **배지**: 알약, `2px var(--ink)` + `0 2px 0 var(--edge)`. `new`=그린, `hot`=코랄. 글자 `--paper-2`.
- **칩(장르/속성)**: 작은 알약, `1.5px var(--ink)`, 반투명 액센트 바닥(`c-rom/fan/day/mys` 등), 800.
- **스티커 말풍선**: `2px var(--ink)` + `--shadow-card`, 꼬리(회전한 정사각+오른/아래 테두리), 밝은 액센트 바닥 + `--on-bright` 글자.
- **입력**: 알약/라운드, `--paper-tint` 바닥. [강]은 `2px var(--ink)`, [약]은 `1px var(--line)`.
- **폼 라벨**: 굵은 한글 라벨(`13.5px`/800). ⚠ **대문자·넓은 자간을 쓰지 않는다** — `text-transform: uppercase`는 한글에 아무 효과가 없고, 넓은 자간의 작은 대문자 라벨은 Reel Theory 잔재다. 필수 표시는 `*`(액센트색).

## 캐릭터 아트 · 이미지

- **전략 = 제작자 업로드** (확정). 각 캐릭터는 **제작자가 올린 일러스트**를 정사각(1:1)으로 담는다. 카드·채팅 헤더·아바타에서 공통 사용.
- 업로드 처리(백엔드): `ChatCharacter`에 `imageUrl` 필드 신설(현재 없음, 아바타=이름 첫 글자). 초기엔 URL 입력 → 이후 업로드/스토리지. 규격·검열(부적절 이미지) 처리 필요. → todos A0-2 / A1.
- **폴백**(이미지 없을 때): 브랜드 그라디언트 배경 + 이름 첫 글자 모노그램(현재 방식 유지). 목업의 SVG 초상은 "이미지가 들어가면 이렇게 보인다"는 자리표시일 뿐, 실제 스타일은 업로더 몫.
- 업로드 이미지는 자기 색을 그대로 유지한다. 카드 배경·테두리만 시스템이 책임진다.
- 비율: 카드·아바타 **1:1 정사각**. 스트리밍 타일 비율·세로 포스터 강요하지 않는다.

## 모션 (Motion)

- 표준 `--dur: 220ms`, `--ease-out: cubic-bezier(.22,1,.36,1)`, `--ease-in-out: cubic-bezier(.65,0,.35,1)`.
- 상호작용: 카드 hover 떠오름, 버튼 hover 시 위로 뜨며 하드 섀도우 커지고 press 시 눌림(섀도우 축소) — "누르는 맛".
- 데코: 스티커 `float`(상하 6s), 메이커 블롭 `wobble`(회전 8s). 은은하고 느슨하게.
- **`prefers-reduced-motion: reduce`** 시 모든 애니메이션·hover 이동 제거(목업에 이미 반영). 필수.

## 아이콘 & 이모지 (Iconography & Emoji)

- **이모지는 유지** (확정). 카피의 💗 ✦ ㅋㅋㅋㅋ 💬 등은 웹툰 팝의 가벼운 톤을 만드는 장치 → 커스텀 아이콘으로 대체하지 않는다.
- 단, **의미 전달을 이모지에만 의존하지 않는다**(접근성): 이모지는 장식, 옆에 텍스트 라벨을 함께 둔다. 순장식 이모지는 `aria-hidden`.
- 아이콘이 필요할 땐 굵은(2px 내외) 둥근 스트로크의 심플 세트. 날카로운 기하보다 둥글게.

## 보이스 & 톤 (Voice & Tone)

- **친구가 말 거는 톤.** 반말/구어체, 가볍고 다정하게. "가볍게 말 걸어보는" 진입장벽 최소.
- 캐릭터 대사는 한 줄 훅(로그라인)으로: "오늘 밤도 네 얘기, 내가 다 들어줄게." 장르 태그 나열 대신 목소리를 보여준다.
- 이모지·`ㅋㅋ` 같은 캐주얼 마크 허용(과하지 않게).
- 빈 상태: 무겁지 않게. "아직 준비 중이야 — 곧 새 친구가 올라와요." 식.
- 정직한 카피: **가짜 지표·후기·숫자 금지**(예: "지금 1,000명 접속 중" 같은 조작 금지). 없는 수치는 쓰지 않는다.

## Do / Don't

**Do**
- 라이트를 base로. 하드 섀도우는 `--edge`, 밝은 배경 글자는 `--on-bright`.
- 액센트를 **글자·링크**로 쓸 땐 명도를 55% 안팎까지 낮춘다(70%대는 흰 바탕에서 안 읽힌다).
- 화면 성격에 따라 강/약 강도를 지킨다: 카탈로그는 팝, **채팅은 차분**.
- 액센트는 멀티로 즐겁게 쓰되 잉크 테두리로 묶어 정돈.
- 캐릭터 대사·이미지가 주인공. 카드는 그걸 담는 틀.

**Don't**
- 채팅 화면에 홈처럼 굵은 테두리·하드 섀도우·쨍한 색을 그대로 밀지 않는다(눈 피로).
- 명조(serif)·필름그레인·레터박스 등 Reel Theory 잔재를 섞지 않는다.
- 하드 오프셋 섀도우에 `var(--ink)`를 직접 쓰지 않는다 → `var(--edge)`(섀도우 색을 한 곳에서 조절하기 위해).
- **다크 테마를 다시 얹지 않는다.** 이 팔레트는 라이트 전제라 표면만 뒤집으면 주 버튼이 깨진다 — 하려면 팔레트를 새로 짜야 한다.
- 밝은 sun/하이라이트/스티커 위에 밝은 잉크 글자를 얹지 않는다 → `var(--on-bright)`.
- 가짜 지표·과장 마케팅 카피·느낌표 남발 금지.
- 의미를 이모지 단독에 싣지 않는다(텍스트 라벨 병기).

## 코드 규약 (Implementation Notes)

이 시스템을 `src/styles.css`에서 다룰 때 지켜야 하는 것들. (무엇이 언제 이식됐는지 같은 **작업 진척은 여기 적지 않는다** — 메모리 `todos.md` A0가 관리한다.)

- **색을 직접 쓰지 않는다.** 하드코딩된 색이 0건이라, 토큰 값만 갈아끼우면 전체가 리스킨된다. 라이트 전환도 `:root` 한 블록으로 끝났다. 이 성질을 깨지 말 것.
- **토큰 이름이 뜻과 어긋난다**(`--ink`가 배경). 레거시(Reel Theory) 이름을 유지하고 값만 바꿔 온 결과다 → [토큰 이름 대응표](#토큰-이름-대응표).
- **레거시 별칭(`--bg/--panel/--primary/--me/--bot`)을 지우지 말 것.** `:root` 하단에 매핑돼 있고 컴포넌트들이 물려 있다.
- **스타일만 확인할 땐 앱에 임시 라우트를 만들지 않는다.** 실제 `styles.css`를 `<link>`로 불러오는 정적 HTML에 같은 클래스로 마크업을 얹으면 된다 — 같은 파일이라 검증이 유효하고 앱에 잔재가 안 남는다. (채팅은 로그인 가드 안이라 이 방법이 특히 유용하다.)
- 참고 목업(자체완결 HTML): 라이트(기본) `7102f03f`, 채팅 강도비교 `88d8429f` — claude.ai/code/artifact/ 하위. 다크 목업 `0cc8fa61`은 폐기.
